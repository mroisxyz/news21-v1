A single 1024x1024 editorial news infographic for **Saturday, 21 November 2026**. The front page packs 35 numbered stories into a scannable layout led by three breaking threads: COP31 climate talks dragging into overtime, a Saudi missile escalation, and a major earthquake in Peru. A UTC timeline anchors every story in time, while a numbered world map ties each item to a location. A dedicated date-check panel confirms the edition date, and a source legend explains the reference markers used throughout so every headline can be verified at a glance.

## Run it

```bash
node main.ts
```

The script copies `entry.png` into `MAKEFUN_OUTPUT_DIR` (default `/output`) and reports the written byte size on stderr.
